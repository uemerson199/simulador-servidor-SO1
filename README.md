# Simulador de um Servidor 
[![NPM](https://img.shields.io/npm/l/react)](https://github.com/uemerson199/exemplo-readme/blob/main/LICENSE) 

# Sobre o projeto
Esse projeto foi desenvolvido durante a disciplina de Sistemas Operacionais 1 do Curso de Engenharia de Computação do IFSULDEMINAS
campus Poços de Caldas, e tem como objetivo a simulação de um Servidor para tratar múltiplas requisições simultâneas
utilizando conceitos de sincronização aprendidos durante a disciplina. 


# Tecnologias utilizadas
- Java
  
## Funcionalidades 
O projeto simula o envio e recebimento de requisições através de interfaces Sockets. Simulando o Cliente e o Servidor na máquina local.

## Ferramentas para executar o projeto
Pré-requisitos: Java 17 ou Superior
